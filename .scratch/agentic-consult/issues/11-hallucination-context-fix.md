## 0. 靶子（AC-10 实测，可直接复现）

v3 的 `llm-explicit-symptoms` 用例里，真实回答中有一条断言：

```
知识图谱初步提示：**慢性肾炎（覆盖率约0.50，科室：肾内科，依据症状：高血压）**
```

确定性层从它取到词表命中 `['高血压', '0.50']`；判定上下文里**没有**「高血压」
（检索分块没提到），于是整条被判**无据**——但「高血压」恰恰是图谱候选
（`infer_diseases` 返回）里的节点名。更短的一例：`llm-headache-alias` 的
`仅说"头疼"还不能判断具体原因，偏头痛、感冒/感染…` 命中词表 `感冒`，
检索上下文里没有、图谱候选里有 `{"disease": "感冒"}`。

**全量实测（v3，AC-10）**：确定性层评估 **400** 条断言，无据 **44** 条（11%），
其中 **10 条**的缺失词出现在图谱结果里——即本缺陷造成的**假无据**。
（这 10 条是 AC-10 给出的**候选分类**，本票要用修复后的真实重算来确认或修正它。）

## 3. TDD 要点

| 用例 | 断言 |
|---|---|
| 图谱片段并入 | 给定只出现在图谱里的疾病名 → 该断言判为**有据** |

## 4. 边界与坑

- **别把「修复」做过头**：上下文里塞进整张图谱（比如把 `full_graph` 全量拼进来）
  会让确定性层几乎什么都能匹配上，幻觉率反而失去意义。**只用这次问诊实际拿到的
  图谱候选**（`ports["graph"]` 的录制返回），与提示词给模型的信息集保持一致。
- **对照必须同基线**：重录 v3 会换掉靶子与上下文，前后就不可比了。
- **记录「修复前的数字」**：spec §8.3 / map 里已经写下 400 / 44 / 10，
  修复后保留它们并注明"修复前"，否则历史与成因就丢了。
- 本票**只影响幻觉率的分母/分子**，不影响拦截率、误拦率、延迟、漂移率（后者恒真）。

#### 那条「模板词调松」的风险：**机制不成立**（实测）

```
模板词是否属于确定性层的词表：一个都不是
```

确定性层只抽**两类 token**：本体里的疾病 / 药品 / 检查名（`_DETERMINISTIC_TERMS`）
与**数字**。五个模板词（"知识图谱" / "推理结果" / "覆盖率" / "科室" / "依据症状"）
既不是词表项、也不是数字，**根本不会成为被匹配的 token**——所以它们进不进上下文，
不改变任何一条断言的判定结果。

**约束仍然保留**（`_GRAPH_TEMPLATE_WORDS` + 一条断言钉住"模板词不得出现在 `_context_of` 返回值里"）：
它是**防御性**的（词表或判定层将来一变，这条通道就会真开），但**不是可测的松弛**——
请不要在汇总里写成"模板词让指标松了 K 条"，那是 0。
