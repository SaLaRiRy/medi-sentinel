# 11: 修确定性幻觉层的判定上下文（并入图谱片段）

**What to build:** 修 `server/regression/replay.py:55-62` 的 `_context_of` —— 它现在
**只用检索端口**的分块拼判定上下文，图谱片段完全不在其中。于是模型**依据图谱结论**说出的
疾病名 / 药品名 / 检查名，会被确定性字面层判成「无据」，把幻觉率抬高。
本票把图谱片段的**文本**并入这份上下文，然后在 v3 上给出**修复前 / 后对照**。

**Blocked by:** 10（v3 活库基线与可复现靶子）

**Status:** needs-triage —— 用户复核票面后置 `ready-for-agent`（**复核通过前不开工**）

---

## 0. 靶子（AC-10 实测，可直接复现）

v3 的 `llm-explicit-symptoms` 用例里，真实回答中有一条断言：

```
知识图谱初步提示：**慢性肾炎（覆盖率约0.50，科室：肾内科，依据症状：高血压）**
```

确定性层从它取到词表命中 `['高血压', '0.50']`；判定上下文里**没有**「高血压」
（检索分块没提到），于是整条被判**无据**——但「高血压」恰恰是图谱候选
（`infer_diseases` 返回）里的节点名。更短的一例：`llm-headache-alias` 的
`仅说"头疼"还不能判断具体原因，偏头痛、感冒/感染…` 命中词表 `感冒`，
检索上下文里没有、图谱候选里有 `{"disease": "感冒"}`。

**全量实测（v3，AC-10）**：确定性层评估 **400** 条断言，无据 **44** 条（11%），
其中 **10 条**的缺失词出现在图谱结果里——即本缺陷造成的**假无据**。
（这 10 条是 AC-10 给出的**候选分类**，本票要用修复后的真实重算来确认或修正它。）

## 1. 范围

### 做

1. **改 `_context_of`（`replay.py:55-62`）**：在检索分块之后，追加图谱片段的文本。
   实现上**优先复用已有一处格式**（`skills/orchestration/prompt.py::graph_fragment`
   就是提示词里给模型看的那段），对缺失字段（`coverage` / `match_count` 在
   `infer_diseases` 的原始返回里不存在）做**宽容处理**。
   关键不是排版，而是**把疾病名 / 科室 / 依据症状这些词面暴露给确定性层**——
   该层只做字面匹配，看不到的词就是「无据」。
2. **在 v3 上重算**并给出修复前 / 后对照（同一份基线，只换判定上下文）：
   `hallucination.total` / `deterministic_ratio` / 无据条数，以及「差值里有多少条
   确实来自这个缺陷」（逐条列给出从无据变成有据的断言）。
3. **更新三处条件标注**：票 10 的 §3、`spec.md` §8.3、`map.md` 的 v3 小节。
   修复后那三段标注要改成「已修复」+ 修复后数字 + 保留原始记录（别直接删掉历史）。

### 不做

- **不动 `drift_rate` 的恒真式性质**。那是一条**独立的**结构性缺陷
  （`replay.py:94-100` 的 `baseline_candidates` 从同一份基线的 frames 读，
  回放喂回同一批数据 → 恒为 0）。修它要让回放**重新执行**，会动摇
  AC-B-35「回放零外部依赖」的地基，属**另一个范围**。
  本票完成后必须再写一遍：**drift 仍然是恒真式，不要因为幻觉率修好了就顺带引用它。**
- 不改 `metrics.py` 的判定算法本身（只换喂给它的上下文）。
- 不重录 v3（那会换掉靶子）；**同一份基线**上做前后对照才有可比性。
- 不动 `llm_chunks` / 帧结构 / 基线 schema。

## 2. 验收

      （不能因为图谱缺失就把上下文清空）。
- [ ] 靶子断言从「无据」变成「有据」（`llm-explicit-symptoms` 那条；
      以及 `llm-headache-alias` 的 `感冒` 那条）。
- [ ] v3 前后对照表落地，且**逐条列出**从无据翻转为有据的断言（不是只给总数）。
- [ ] **差值归因说清楚**：44 → N 条无据里，多少条来自本缺陷、剩余来自真正的幻觉
      （模型说了检索与图谱都不支持的内容）——后者**不该**被这次修复洗掉。
- [ ] 三处条件标注更新为「已修复 + 修复后数字 + 保留原始记录」。
- [ ] 明确重申 `drift_rate` 仍是恒真式（写进票面与 `spec.md` §8.5）。
- [ ] 既有测试全绿：确认没有测试依赖 `_context_of` 的**旧**行为。

## 3. TDD 要点

| 用例 | 断言 |
|---|---|
| 图谱片段并入 | 给定只出现在图谱里的疾病名 → 该断言判为**有据** |
| 空图谱不退化 | `ports["graph"] == []` 时，上下文与修复前**逐字相同** |
| 真正的幻觉仍被抓 | 模型说了既不在检索、也不在图谱里的药名 → 仍判**无据** |
| 判定层也吃到图谱 | `judge` 收到的 context 同样含图谱片段（两层的上下文必须一致） |
| 靶子回归 | 用 AC-10 记下的那条真实断言做断言级测试（可离线，数据取自 v3 基线） |
| drift 不受影响 | 同一次改动后，`build_report` 的 `diagnosis_drift_rate` **仍是 0**（预期恒真式） |

## 4. 边界与坑

- **别把「修复」做过头**：上下文里塞进整张图谱（比如把 `full_graph` 全量拼进来）
  会让确定性层几乎什么都能匹配上，幻觉率反而失去意义。**只用这次问诊实际拿到的
  图谱候选**（`ports["graph"]` 的录制返回），与提示词给模型的信息集保持一致。
- **对照必须同基线**：重录 v3 会换掉靶子与上下文，前后就不可比了。
- **记录「修复前的数字」**：spec §8.3 / map 里已经写下 400 / 44 / 10，
  修复后保留它们并注明"修复前"，否则历史与成因就丢了。
- 本票**只影响幻觉率的分母/分子**，不影响拦截率、误拦率、延迟、漂移率（后者恒真）。
