# 12: 认证与个人中心（端到端）

**What to build:** 三角色的进入与自我管理：患者自助注册与登录、医生与管理员的登录、个人资料读写、改密、头像上传，以及前端按角色放行的路由守卫与两套外壳。它是后面所有业务域的入口。

**Blocked by:** 01（工程骨架与契约 seam）、02（Skill 协议与 trace 基座）

**Status:** ready-for-agent

- [ ] 三角色登录（`user` / `doctor` / `admin`）与患者注册可用；角色类型非法返回 400，用户名已存在返回 409
- [ ] 令牌以 `Authorization: Bearer` 传递；401 覆盖无令牌、令牌无效或过期、载荷不完整、账号不存在；403 覆盖角色不匹配与账号被禁用
- [ ] 个人资料读/写、改密、头像上传可用；超过配置上限返回 413
- [ ] 同一用户名可在三张账号表中并存，由登录时选择的角色决定查哪张表
- [ ] 路由守卫是前端唯一鉴权落点；未知角色清理本地鉴权并跳转登录页
- [ ] 401 清理本地鉴权并跳登录页；403 仅展示错误提示，不清理鉴权、不跳转
- [ ] 门户外壳与管理台外壳就位；侧边菜单管理员 10 项、医生 4 项，个人中心仅从用户下拉进入
