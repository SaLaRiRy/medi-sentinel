# 05: vector-retrieval 向量检索 Skill

**What to build:** 把知识库文档分块、向量化并做相似度检索的能力，返回知识片段与引用来源供回答组装。它是编排里的增强支路之一：不可用时降级而不阻断问答。嵌入模型的调用不算大模型生成调用。

**Blocked by:** 02（Skill 协议与 trace 基座）

**Status:** ready-for-agent

- [ ] 给定问题返回知识片段与引用来源（序号、文件名、正文前 200 字符）
- [ ] 记录每条命中的距离
- [ ] 嵌入模型调用不构成大模型调用：大模型端口为抛异常假实现时全部测试仍通过
- [ ] 向量索引不可用时返回 `degraded`，不抛错，问答可继续
- [ ] `SKILL.md` 四节齐备，用例已转为可执行测试且全部通过
- [ ] Skill 可在不启动关系库、图库、向量索引的前提下被单独调用
