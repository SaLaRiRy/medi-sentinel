# 02: Skill 协议与 trace 基座

**What to build:** 五个 Skill 共用的运行基座：统一 `invoke(input) → output` 协议（输入输出按 `SKILL.md` 声明的 Schema 校验，不合规输入返回校验失败而非静默继续）、每次调用产出的 span，以及图谱 / 检索 / 大模型三个外部资源端口。有了它，「Skill 可独立测试」与「红旗命中时大模型调用次数为 0」才成为可断言的事。

**Blocked by:** 01（工程骨架与契约 seam）

**Status:** ready-for-agent

- [ ] 每次 Skill 调用恰好产生一条 span，每次大模型调用恰好产生一条 span；span 含 trace_id、Skill 名、耗时、输入摘要、输出摘要
- [ ] 输入或输出不符合声明的 Schema 时返回校验失败，不静默继续
- [ ] 一次问诊内 trace_id 全局一致，可按 trace_id 取回全部 span 并按时间顺序还原
- [ ] 每次编排产生一条路由记录：本轮执行了哪些 Skill、跳过了哪些、跳过理由
- [ ] 摘要字段长度受配置上限约束；患者原文与大模型完整输出不以完整形式落库
- [ ] 三个端口可被注入计数假实现；五个 Skill 可在不启动关系库、图库、向量索引的前提下被单独实例化并调用
- [ ] trace 汇聚实现提供内存替身，可断言写入内容而不触碰数据库
