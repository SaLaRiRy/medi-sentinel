# 16: 图谱可视化与症状推理

**What to build:** 把医学图谱摆到台面上：公开的全图、实体邻域、关键字搜索与疾病详情四个只读接口，加上患者侧的症状推理页和管理端的图谱页。医生和患者都能看到候选疾病是怎么按覆盖率排出来的。

**Blocked by:** 06（graph-inference）、13（图谱与知识库种子数据）

**Status:** ready-for-agent

- [ ] 四个公开只读接口可用：全图、实体邻域、关键字搜索、疾病详情
- [ ] 邻域查询的 `depth` 参数真实生效，或该参数被移除；不存在无效参数
- [ ] 症状推理按 `coverage` 排序展示候选疾病；`coverage` 缺失时不展示进度条
- [ ] 对外不出现 `probability` 字段
- [ ] 节点按标签着色（疾病 / 症状 / 其他），关系名按既定映射展示，未知值回退原文
- [ ] 图谱不可用时页面呈现可理解的错误或空态，而非静默空白
