# 痛风与高尿酸血症

## 常见表现
痛风是尿酸盐结晶沉积在关节与软组织引起的炎症性疾病。典型首发是
**夜间突发的单关节剧痛**，最常见于第一跖趾关节（大脚趾根部），
关节红、肿、热、痛，24 小时内达到高峰，1–2 周可自行缓解。

## 高尿酸血症与痛风的关系
血尿酸男性 >420 μmol/L、女性 >360 μmol/L 定义为高尿酸血症。
多数高尿酸血症者终身不发作，但尿酸持续偏高会增加痛风、尿酸性肾结石
与肾损害风险。**无症状高尿酸血症不一定需要立即用药**，需评估合并症。

## 常见诱因
- 高嘌呤饮食：动物内脏、浓肉汤、沙丁鱼与贝类
- 饮酒（尤其是啤酒）与含果糖饮料
- 突然受凉、剧烈运动、外伤或手术
- 利尿剂、小剂量阿司匹林等药物
- 快速减重或长时间饥饿

## 急性发作期处理
- 尽早使用抗炎止痛药：非甾体抗炎药、秋水仙碱或糖皮质激素
- **急性期不启动或调整降尿酸药**，以免血尿酸波动加重发作；
  已在服用者不要擅自停药
- 抬高患肢、局部冷敷，避免热敷与按摩
- 多饮水，每日尿量保持在 2000 mL 以上

## 降尿酸治疗
- 目标：多数患者血尿酸长期 <360 μmol/L；有痛风石者 <300 μmol/L
- 抑制生成：别嘌醇（用药前建议筛查 HLA-B*5801）、非布司他
- 促进排泄：苯溴马隆，需保证充足尿量，肾结石者慎用
- 起始降尿酸时通常联用低剂量秋水仙碱预防发作，持续 3–6 个月

## 何时必须就医
- 首次发作的关节红肿热痛，需与化脓性关节炎鉴别
- 发热伴关节剧痛、寒战
- 肾功能异常、尿量明显减少或肾绞痛
- 反复发作、出现痛风石或关节畸形

## 饮食与生活方式
限制动物内脏、浓汤与贝类，减少饮酒与含果糖饮料，多饮水；
控制体重与血脂，规律运动但避免突然剧烈运动；
急性期过后可适量摄入低脂奶制品与新鲜蔬菜。
