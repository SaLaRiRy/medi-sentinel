# 感冒与流感鉴别及处理

## 普通感冒
由多种病毒（主要是鼻病毒）引起的上呼吸道感染。

### 常见症状
- 鼻塞、流涕（清水样→粘稠）
- 咽痛、咳嗽
- 低热或无发热
- 全身症状较轻

### 处理建议
- 休息、多饮水
- 对症用药：退热（体温>38.5°C）、止咳、缓解鼻塞
- 病程一般7-10天自愈
- 不推荐常规使用抗生素

## 流行性感冒
由 influenza 病毒引起，传染性强，全身症状重。

### 常见症状
- 突发高热（39-40°C）
- 头痛、全身肌肉酸痛
- 明显乏力
- 咳嗽、咽痛

### 处理建议
- 48小时内可使用抗病毒药物（奥司韦）
- 充分休息，隔离防护
- 高热时使用退热药
- 警惕并发症：肺炎、心肌炎

## 何时就医
- 高热持续超过3天
- 呼吸困难或胸痛
- 症状持续超过10天无好转
- 出现严重头痛、意识改变

## 常用药物
- 退热镇痛：对乙酰氨基酚或布洛芬，二者不叠加、不超量
- 抗病毒：奥司他韦属处方药，需在发病 48 小时内由医生评估使用
- 复方感冒药常含相同成分，与单一成分药同服容易造成过量

## 预防措施
- 每年接种流感疫苗，是降低重症风险最有效的手段
- 流行季节勤洗手、戴口罩、开窗通风，避免人群密集场所
- 出现症状后居家休息，咳嗽、打喷嚏时遮掩口鼻
