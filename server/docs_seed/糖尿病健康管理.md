# 糖尿病健康管理

## 糖尿病概述
糖尿病是一组以高血糖为特征的代谢性疾病。主要分为1型糖尿病、2型糖尿病和妊娠糖尿病。

## 典型症状（三多一少）
- 多饮：口渴明显，饮水量增多
- 多尿：尿量增多，夜尿频繁
- 多食：食欲亢进，容易饥饿
- 体重下降：不明原因体重减轻

## 诊断标准
- 空腹血糖 ≥ 7.0 mmol/L
- 餐后2小时血糖 ≥ 11.1 mmol/L
- 糖化血红蛋白 ≥ 6.5%

## 综合管理
1. **饮食控制**：控制总热量，低GI饮食，定时定量
2. **运动疗法**：每周至少150分钟中等强度运动
3. **药物治疗**：口服降糖药或胰岛素
4. **血糖监测**：定期检测空腹及餐后血糖
5. **并发症筛查**：眼底、肾脏、足部检查

## 急性并发症
- 低血糖：出汗、心慌、饥饿感，需立即补充糖分
- 酮症酸中毒：恶心、呕吐、呼吸深快，需紧急就医

## 饮食建议
推荐：粗粮、绿叶蔬菜、优质蛋白（鱼、豆制品）
限制：精制碳水、含糖饮料、高糖水果
