# 缺铁性贫血

## 常见表现
缺铁性贫血是最常见的贫血类型，起病缓慢。典型表现包括**乏力、头晕、
活动后心悸气短、面色与指甲苍白**，还可能出现注意力不集中、脱发、
口角开裂与异食癖（如想吃冰、泥土）。部分患者以「走几步就喘」就诊。

## 常见病因
- 慢性失血：月经量多、消化道溃疡、痔疮、肿瘤、长期服用阿司匹林
- 摄入不足：长期素食、挑食、减肥节食
- 吸收障碍：慢性胃炎、胃切除术后、乳糜泻
- 需求增加：妊娠期、哺乳期、婴幼儿与青少年生长发育期

## 需要做的检查
- 血常规：血红蛋白降低、平均红细胞体积（MCV）偏小
- 铁代谢：血清铁蛋白降低是最敏感指标；总铁结合力升高
- 病因筛查：女性查妇科与月经量，中老年人需做胃肠镜排除消化道肿瘤

## 治疗原则
1. **补铁治疗**：口服铁剂（硫酸亚铁、琥珀酸亚铁、多糖铁复合物），
   餐后服用可减轻胃肠刺激，与维生素 C 同服促进吸收
2. **避免同服**：浓茶、咖啡、牛奶、钙片与抗酸药会明显降低铁吸收
3. **疗程**：血红蛋白恢复正常后仍需继续补铁 3–6 个月，补足储存铁
4. **病因治疗**：找到并纠正失血或吸收障碍的原因，否则容易复发

## 静脉补铁
口服铁剂不耐受、吸收障碍或需快速纠正贫血者（如妊娠中晚期、术后），
可由医生评估静脉输注铁剂。

## 何时必须就医
- 血红蛋白明显降低伴活动后气促、心悸、下肢水肿
- 大便发黑或带血、体重不明原因下降
- 补铁 4 周后血红蛋白无上升
- 男性或绝经后女性出现缺铁性贫血，必须排查消化道出血

## 饮食建议
红肉、动物肝脏、动物血制品中的血红素铁吸收率最高；搭配富含维生素 C 的
新鲜蔬果可进一步提升吸收。植物性食物中的非血红素铁吸收率较低，
需长期合理搭配。
