# 颈椎病与腰肌劳损

## 颈椎病的常见类型
- **颈型**：颈肩部酸痛、僵硬，转头受限，最常见，多与长期低头有关
- **神经根型**：一侧上肢放射性疼痛、麻木，咳嗽或用力时加重
- **脊髓型**：手部精细动作变差、走路踩棉花感、大小便异常，**需尽快手术评估**
- **椎动脉型与交感型**：头晕、耳鸣、视物模糊，诊断需谨慎

## 腰肌劳损的常见表现
腰部酸胀、隐痛，久坐久站后加重，卧床休息可缓解；疼痛多位于腰骶部两侧，
可向臀部放射但一般不超过膝关节。与腰椎间盘突出不同，后者常伴下肢
放射性疼痛、麻木与肌力下降。

## 需要做的检查
- 单纯颈肩痛或腰痛、无神经症状者，多无需影像学检查
- 出现肢体麻木、无力、大小便异常，或外伤后疼痛，需做磁共振或 CT
- 长期疼痛伴消瘦、夜间痛醒、发热，需排除感染与肿瘤

## 保守治疗
1. **急性期**：减少负重与低头，短期卧床不超过 2–3 天，避免长期卧床
2. **药物**：非甾体抗炎药（布洛芬、塞来昔布）减轻疼痛与炎症；
   肌肉紧张明显者可短期使用肌松剂
3. **物理治疗**：热敷、牵引、按摩与针灸对部分患者有效，
   **脊髓型颈椎病禁用牵引与大力按摩**
4. **功能锻炼**：颈深肌群与腰背核心肌群训练是长期改善的关键

## 日常姿势要点
- 屏幕与视线齐平，肘部有支撑，避免长时间低头看手机
- 每坐 45–60 分钟起身活动 3–5 分钟
- 搬重物时屈髋屈膝、保持腰部中立，不要直接弯腰
- 床垫不宜过软，枕头高度以侧卧时颈椎保持水平为准

## 何时必须就医
- 上肢或下肢进行性无力、肌肉萎缩
- 大小便功能障碍、会阴部麻木（马尾综合征，属急症）
- 疼痛剧烈且夜间加重、伴发热或体重下降
- 外伤后出现颈部或腰部剧痛
