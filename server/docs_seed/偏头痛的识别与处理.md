# 偏头痛的识别与处理

## 常见表现
偏头痛是一种反复发作的原发性头痛，多见于中青年女性。典型特征是**单侧、
搏动性、中重度**头痛，持续 4–72 小时，日常体力活动会加重，
常伴恶心、呕吐、畏光与畏声。

## 先兆
约三分之一患者在头痛前出现可逆的先兆，最常见的是视觉先兆：眼前闪光、暗点、
锯齿状亮线，逐渐扩大，通常持续 5–60 分钟。也可出现一侧肢体麻木或言语不清。
**首次出现先兆必须就医排除脑血管病。**

## 常见诱因
- 睡眠不足或过度睡眠、作息突然改变
- 精神紧张、情绪波动、过度劳累
- 特定食物：红酒、奶酪、巧克力、含味精或亚硝酸盐的加工食品
- 月经期前后雌激素水平波动
- 强光、噪音、闷热环境与浓烈气味

## 发作期处理
- 在安静、避光、避声的环境中休息，必要时睡眠
- 尽早使用止痛药：布洛芬、对乙酰氨基酚或萘普生
- 中重度发作或普通止痛药无效时，医生可能开具曲普坦类药物
- **每月使用止痛药不超过 10 天**，否则可能诱发药物过度使用性头痛

## 需要做的检查
有典型先兆与既往史的偏头痛通常无需影像学检查。出现以下情况时需做头颅 CT
或磁共振：突发剧烈头痛（霹雳样）、50 岁后新发头痛、头痛模式明显改变、
伴发热与颈项强直、伴神经系统体征。

## 何时必须就医
- 突发「一生中最剧烈」的头痛
- 头痛伴发热、颈项强直、皮疹或意识改变
- 头痛伴肢体无力、言语不清、视物成双或抽搐
- 头痛进行性加重，或咳嗽、用力、体位改变时明显加重
- 妊娠期或产后新发严重头痛

## 预防与长期管理
记录头痛日记，标注发作时间、诱因、用药与缓解情况，有助于识别诱因与评估疗效。
发作频繁（每月 ≥4 次）或明显影响生活者，医生可能建议预防性用药，
如 β 受体阻滞剂、氟桂利嗪或托吡酯。规律作息、适量运动、
减少咖啡因摄入对减少发作有帮助。
