# 尿路感染

## 常见表现
尿路感染多见于女性，典型症状是**尿频、尿急、尿痛**（合称膀胱刺激征），
可伴下腹坠胀与尿液浑浊、异味，部分患者出现肉眼血尿。
累及肾脏（肾盂肾炎）时会出现**发热、寒战与腰痛**，属需要及时治疗的感染。

## 常见诱因
- 女性尿道短而直，且靠近肛门，细菌易逆行感染
- 饮水少、憋尿、久坐
- 性生活后未及时排尿
- 糖尿病、免疫抑制、妊娠、绝经后雌激素水平下降
- 留置导尿管或泌尿系结石、前列腺增生导致排尿不畅

## 需要做的检查
- 尿常规：白细胞、亚硝酸盐与红细胞
- 尿培养 + 药敏：反复发作、治疗失败或怀疑肾盂肾炎时必做
- 血常规与 C 反应蛋白：评估是否存在上尿路感染
- 反复发作的男性患者或复杂性感染，需做泌尿系超声排除梗阻

## 治疗原则
- 单纯性膀胱炎：常用呋喃妥因、磷霉素氨丁三醇、第二代头孢等短程治疗
- **必须按医生处方足量足疗程**，症状缓解后擅自停药易复发
- 肾盂肾炎通常需 7–14 天疗程，严重者需静脉用药
- 孕期尿路感染需积极治疗，药物选择由医生评估

## 居家护理
- 每日饮水 1500–2000 mL，勤排尿，不憋尿
- 注意会阴清洁，排便后由前向后擦拭
- 性生活后及时排尿
- 避免长期使用含香精的洗液冲洗阴道
- 反复发作者可在医生指导下采取预防措施

## 何时必须就医
- 发热、寒战、明显腰痛或恶心呕吐（提示肾盂肾炎）
- 肉眼血尿、尿量明显减少
- 妊娠期出现尿路感染症状
- 男性出现尿路感染症状（多提示复杂性感染）
- 症状超过 48 小时不缓解，或停药后短期内复发
