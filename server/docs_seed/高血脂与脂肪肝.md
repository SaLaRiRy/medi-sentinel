# 高血脂与脂肪肝

## 什么是高血脂
血脂主要包括总胆固醇、甘油三酯、低密度脂蛋白胆固醇（LDL-C）与
高密度脂蛋白胆固醇（HDL-C）。**LDL-C 是动脉粥样硬化最重要的危险因素**，
俗称「坏胆固醇」；HDL-C 偏低同样是风险。高血脂通常没有症状，
多在体检时发现。

## 血脂控制目标
- 一般人群 LDL-C <3.4 mmol/L
- 合并高血压、糖尿病或吸烟等危险因素者 <2.6 mmol/L
- 已患冠心病、脑卒中或糖尿病伴靶器官损害者 <1.8 mmol/L，甚至更低
- 甘油三酯 ≥5.6 mmol/L 时需优先降甘油三酯，以降低急性胰腺炎风险

## 生活方式干预
- 减少饱和脂肪与反式脂肪：少吃肥肉、动物内脏、油炸食品与糕点
- 增加膳食纤维：燕麦、豆类、蔬菜与水果
- 每周 150 分钟中等强度有氧运动，配合抗阻训练
- 戒烟限酒，控制体重，减重 5%–10% 即可明显改善血脂

## 常用降脂药物
- 他汀类：阿托伐他汀、瑞舒伐他汀，是降低 LDL-C 的一线药物；
  用药期间需监测肝功能与肌酸激酶，出现肌肉酸痛无力要及时就诊
- 依折麦布：抑制胆固醇吸收，常与他汀联用
- 贝特类：非诺贝特，主要用于高甘油三酯血症
- PCSK9 抑制剂：用于家族性高胆固醇血症或他汀不耐受的高危患者

## 脂肪肝
脂肪肝指肝细胞内脂肪蓄积超过 5%，最常见的是与肥胖、糖尿病、
高血脂相关的**代谢相关脂肪性肝病**。多数无症状，部分人出现
乏力、右上腹隐痛，体检可见转氨酶轻度升高。

### 脂肪肝的处理
- **减重是核心**：减重 5% 可改善脂肪变，减重 7%–10% 可改善炎症
- 控制血糖、血脂与尿酸；避免含果糖饮料与过量饮酒
- 不推荐盲目服用「保肝保健品」；转氨酶升高需评估原因
- 定期做肝脏超声与肝功能检查，明显纤维化风险者需进一步评估

## 何时必须就医
- 甘油三酯 ≥5.6 mmol/L，或伴剧烈上腹痛（急性胰腺炎风险）
- 服用他汀后出现明显肌肉疼痛、无力或尿色变深
- 转氨酶持续升高、出现黄疸或腹胀
- 有早发冠心病家族史，或体检发现血脂显著升高
