# 慢性胃炎与幽门螺杆菌

## 常见表现
慢性胃炎常见症状是**上腹隐痛、餐后饱胀、早饱、嗳气、反酸与恶心**，
症状多与进食相关，但**症状轻重与胃黏膜病变程度并不平行**——
很多人胃镜下有明显炎症却几乎没有不适。

## 常见病因
- 幽门螺杆菌（Hp）感染：慢性胃炎最主要的病因
- 长期服用非甾体抗炎药（阿司匹林、布洛芬等）
- 胆汁反流、长期饮酒、吸烟、浓茶与咖啡
- 自身免疫因素（多见于萎缩性胃炎伴恶性贫血）

## 幽门螺杆菌的检测
- **碳 13 / 碳 14 尿素呼气试验**：最常用，无创、准确，需空腹进行，
  且检查前 4 周内未服用抗生素、2 周内未服用质子泵抑制剂
- 胃镜检查时可行快速尿素酶试验或组织学检查
- 血清抗体阳性只能说明曾经感染，不能判断现症感染

## 根除治疗
目前推荐**含铋剂四联方案**：质子泵抑制剂 + 铋剂 + 两种抗生素，
疗程 10–14 天。关键点：
- 必须按疗程足量服用，漏服与提前停药是失败的主因
- 常用抗生素包括阿莫西林、克拉霉素、呋喃唑酮、四环素等，
  青霉素过敏者需告知医生
- **停药 4 周后复查呼气试验**确认根除，不能凭症状改善判断
- 治疗期间避免饮酒，注意口腔卫生，家庭成员可考虑共同筛查

## 胃镜与随访
以下情况建议做胃镜：年龄 >40 岁首次出现上腹症状、有报警症状、
胃癌家族史、萎缩性胃炎或肠上皮化生需定期随访。

## 何时必须就医
- 呕血、黑便或大便潜血持续阳性
- 不明原因消瘦、贫血、吞咽困难
- 上腹痛规律改变、夜间痛醒
- 规范治疗后症状仍加重

## 日常饮食
规律三餐、细嚼慢咽，避免过饱与睡前进食；减少辛辣、过酸、腌制与熏制食物；
戒烟限酒。饮食调整能减轻症状，但不能替代 Hp 根除治疗。

资料来源：常见医学科普要点整理，仅供学习演示，不构成诊疗建议。
